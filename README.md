# Hockey Maze Game

Hockey Maze Game is a 2D game developed in Godot in which the player navigates hockey-themed maze environments while avoiding enemies and progressing toward level goals.

The project was developed as an academic game-development project and provided experience with gameplay programming, scene management, UI systems, enemy behavior, level design, and Godot's node-based architecture.

## Features

- 2D maze-based gameplay
- Multiple game scenes and levels
- Player movement and collision
- Moving enemy obstacles
- Goal and level-completion systems
- Main menu and pause menu
- Game-over flow
- Coordinate/debugging tools
- Custom level-development utilities

## Technology

- Godot
- GDScript
- 2D game development
- Scene-based architecture
- UI and menu systems
